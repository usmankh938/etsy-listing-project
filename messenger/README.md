# Relay

Mobile messenger you can run in the browser. Sample chats are preloaded so the inbox is usable on first open. Messages you send stay in this browser.

## Run

```bash
cd messenger
npm install
npm run dev
```

Open http://127.0.0.1:5173

On a phone-sized viewport the chrome fills the screen. On desktop it sits in a device frame.

## Try

- Open **Aisha Khan** or **Saturday studio**
- Send a message — you get a short reply
- Search chats, then check **Calls**, **People**, and **Settings**
